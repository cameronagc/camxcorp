FREE PUBLISHING OPTION — GITHUB PAGES
1. Create a free account at https://github.com/ if you do not already have one.
2. Create a new public repository named: camxcorp-website
3. Upload index.html to the top/root of the repository.
4. Open the repository's Settings > Pages.
5. Under Build and deployment, choose "Deploy from a branch".
6. Select the main branch and /(root), then Save.
7. GitHub will publish a free link, usually:
   https://YOUR-GITHUB-USERNAME.github.io/camxcorp-website/

NOTES
- GitHub Pages provides free hosting for a static brochure website. You do not need to buy a hosting plan.
- The free address uses github.io. A custom domain such as camxcorp.com is optional and normally costs a separate annual domain-registration fee.
- The sample residential photos are loaded from Unsplash over the internet. Replace their image URLs in the CSS with your own property photographs when ready.
- This draft uses the brochure's navy, gold, and white style and includes the six-property statement, services, audience, and contact details.
- Review all wording and confirm services/eligibility details before publishing.
